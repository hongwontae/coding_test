1. 1+1 -> 10
    char a = '1';
    char b = '1';

    int carry = 0;

    int sum = (a - '0') + (b - '0') + carry;

    int bit = sum % 2;
    carry = sum / 2;

    printf("현재 자리: %d\n", bit);
    printf("올림: %d\n", carry);

    1-1. carry는 1+1 -> 올림 수. -> 합산 결과 2라면 1을 올려야 함 -> 이진수
    1-2. sum은 더한 결과 + carry
    1-3. bit는 현재 자리 비트 숫자
        => 이진수에서는 한 자리에 0 또는 1만 들어갑니다.
        => 십진수 덧셈에서 8 + 7 = 15
        => 나머지 연산으로 자릿수 구할 수 있음 -> 15 % 10 = 5, 15 / 10 = 1;
