1. 소문자 -> 대문자 / 대문자 -> 소문자 변환 함수
    1-1. #include <ctype.h>를 사용합니다.
    1-2. toupper(문자) -> 소문자를 대문자로 바꾼 char를 return
    1-3. tolower(문자) -> 대문자를 소문자로 바꾼 char를 return
    1-4. 변환할 수 없는 문자(숫자, 기호)는 그대로 반환합니다.
    1-5. 인수는 unsigned char로 표현할 수 있는 값 / 인자로 넣을 떄는 (unsigned char) 변환하는 것이 안전합니다.


2. 소문자, 대문자 판별 함수
    2-1. isupper(char) -> 대문자라면 1 / 그렇지 않으면 0
    2-2. islower(char) -> 소문자라면 1 / 그렇지 않으면 0
