1. 팩토리얼
    1-1. 1부터 특정 숫자까지의 모든 자연수를 차례대로 곱하는 것입니다.
    1-2. 5! -> 5 * 4 * 3 * 2 *1 = 120
    1-3. !는 팩토리얼을 나타내는 수학 기호입니다.
    1-4. 팩토리얼 규칙 -> 이전 팩토리얼에 현재 숫자를 곱하면 다음 팩토리얼이 됩니다.
        => 3! = 6
        => 4! = 3! * 4
        => 5! = 4! * 5


2. 팩토리얼 알고리즘
    2-1. 특정 수를 넘기는 팩토리얼 중 가장 작은 수를 찾아야 합니다.
    2-2. 계산 결과와 팩토리얼이 일치해야 return 할 떄 -1이 구해집니다.
    2-3. 즉, 팩토리얼 숫자를 먼저 증가시키고 -> 팩토리얼 계산 -> while 비교.. -> 넘어섰으면 return에 -1
    2-4. 만약 계산 먼저 -> 팩토리얼 증가 -> while 비교 -> num이 1일 떄 factorial_num이 2가 됩니다. -> 이상한 결과 도출됨
    int solution(int n) {

    int num = 1;
    int factorial_num = 1;

    while (num <= n) {
        factorial_num++;
        num *= factorial_num;
    }

    return factorial_num - 1;
}



3. 팩토리얼 + 조합 알고리즘
    3-1. 경우의 수란 어떤 일이 일어날 모든 가능한 방법의 개수입니다.
        => 구슬 a,b,c가 존재할 떄 2개를 고른다면? -> a,b / b,c / a,c 3개의 경우의 수가 존재합니다.
    
    3-2. 경우의 수는 순열과 조합이 존재합니다.
        => 순열 : 서로 다른 것 중 몇 개를 골라 순서대로 나열합니다.
        => 조합 : 서로 다른 것 중 몇 개를 선택
    => 순열은 a,b,c 중에서 2개를 고를 떄 ab와 ba를 서로 다른 경우라고 봅니다. -> 6가지
    => 조합은 a,b와 b,a를 같은 경우라고 봅니다. -> 3가지

    3-3. 조합의 공식
        => 서로 다른 n개에서 r개를 고르는 조합의 공식은 n! / (n-r)! * r!;
        => 팩토리얼을 사용하는 것보다 약분을 이용하는 것이 좋습니다. -> long long int가 표현할 수 있는 숫자 범위 -> !20
        => n이 6이고 r이 3일 때 -> n!은 6,5,4,3,2,1 / (n-r)! * r!은 3! * 3! -> 약분하면 6 * 5 * 4 / 1 * 2* 3
        => for (int i = 1; i <= share; i++) {
            result = result * (balls - i + 1) / i;
        }
    
    3-4. 매 단계의 나눗셈 결과가 정수임이 보장되고, 계산 중 오버플로우가 발생하지 않는다면, 분자와 분모를 한꺼번에
            계산하지 않고 순차적으로 곱하고 나누는 방법을 사용할 수 있습니다.
        => result * (balls - i + 1) / i;
