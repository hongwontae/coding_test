1. 한 자리 수이고 계산의 대상일 떄 ASCII 코드의 정수값으로 계산됩니다.

2. 이 떄 '0' ~ '9' 까지는 순차대로 이어집니다.
    => 즉, '9' - '0'은 정수 9가 나옵니다.
    => 순차적으로 이어져 정수로 표현되기 때문입니다.


3. ASCII 코드 상 소문자-대문자는 32입니다.
    => 즉, 'a' - 'A' = 32;
    => 대문자에서 소문자로 바꾸려면 +32
    => 소문자에서 대문자로 바꾸려면 -32


4. sprintf() / snprintf()
    => 서식에 맞춰 데이터를 문자열로 변환해 저장하는 함수입니다.
    => sprintf(문자열_주소, 서식, 데이터);
    => snprintf(문자열_주소, 데이터_크기(sizeof), 서식, 데이터);
    => 두 함수 모두 문자열의 끝에 자동으로 널을 추가합니다.


5. atoi() / strtol()
    5-1. atoi() -> 문자열을 int로 변환하는 간단한 함수입니다.
        => atoi는 문자열의 숫자를 읽다가 숫자로 해석할 수 없는 문자를 만나면 변환을 중지합니다. -> 123abc -> 123
    5-2. strtol() -> 문자열을 long으로 변환하여, 진법 지정과 오류 검사가 가능한 함수입니다.
        => strtol(str, endptr, base)
        => str은 변환할 문자열, endptr은 변환이 끝난 위치를 전달받을 포인터, base는 변환할 숫자의 진법
        => char* end;
        => long num = strtol("123abc", &end, 10);
        => strtol을 사용했을 떄 123을 num에 저장하고 end에 a의 주소를 저장합니다.
