1. 합성수
    => n 이하의 수에서 약수가 3개인 수들을 의미합니다.


2. 합성수 알고리즘
    2-1. n1 % n2 == 0이면 n2는 약수입니다.
        => 일단 1과 자기 자신은 약수에 포함됩니다.
        => 그리고 for문이 2부터 시작하고 자기 자신을 제외하면서 돕니다.
        => 그 떄 n1 % n2 == 0이 나오면 그 수는 n1의 약수가 되면서 3개가 됩니다.


3. 합성수 코드
int solution(int n) {
    int count = 0;

    for (int i = 4; i <= n; i++) {
        for (int j = 2; j < i; j++) {
            if (i % j == 0) {
                count++;
                break;
            }
        }
    }

    return count;
}
