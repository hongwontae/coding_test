1. strcmp(문자열_주소, 문자열_주소);
    => 두 문자열을 비교해서 0, 음수, 양수를 반환합니다
    => 0이면 같음 / 음수라면 첫 번째 문자열이 사전식으로 앞섬 / 양수라면 두 번쨰 문자열이 사전식으로 앞섬


2. strstr(문자열_주소, 문자열_주소);
    => char name [] = "hello world";
    => strstr(name, "world") -> 대체로 이렇게 사용합니다.
    => world가 시작되는 첫 번쨰 주소를 반환합니다.
    => 찾으려면 문자열이 없다면 NULL을 반환합니다.
