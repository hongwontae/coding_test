1. 분수 덧셈 알고리즘
    => 1/2 + 2/3
    => 분자는 (2*2) + (1*3) / 분모는 (2*3)
    => 결과는 7/6


2. 기약분수는 분자와 분모의 최대 공약수가 1인 분수입니다.


3. 최대 공약수
    => 두 정수가 존재할 떄 두 정수를 모두 나누어떨어지게 하는 공약수(공통된 약수) 중 가장 큰 수
    => 12의 약수 (1, 2, 3, 4, 6, 12) / 18의 약수 (1, 2, 3, 6, 9, 18)
    => 공통된 약수 (1, 2, 3, 6) / 이 떄 가장 큰 약수 6를 최대공약수라고 합니다.


4. 유클리드 호제법
    => 두 정수의 최대공약수를 효율적으로 구하는 알고리즘입니다.
    => 가장 큰 수를 기준으로 18 % 12 = 6
    => 12 % 6 = 0
    => 0이 나온 순간 나누는 수가 최대공약수입니다.


5. c 언어로 구현
int gcd(int a, int b) {
    while (b != 0) {
        int temp = a % b;
        a = b;
        b = temp;
    }

    return a;
}
