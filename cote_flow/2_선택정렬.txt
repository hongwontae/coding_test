1. 선택정렬에서 p[i]인 select는 갱신되어야 하고 그 정보를 바탕으로 나중에 교환해야 합니다.


2. 코드
    2-1. 첫 번째 코드는 select이 갱신되지 않고 박힌 상태로 비교합니다.
        => 만약 내부 for문에서 선택 정렬에 해당된다면 비교할 대상을 바꾸고 계속 내려가야 합니다.
        => 그렇지 않고 같은 값으로 계속 비교하였기에 올바른 계산이 되지 않았습니다.
    2-2. 두 번쨰 코드는 select 비교 true라면 select을 바꾸면서 비교하고 교체는 외부 for문 아래에서 진행했습니다.

    for (int i = 0; i < count-1; ++i) {
        int select = p[i].rank_number;
        
        for (int j = i+1; j < count ;j++) {
            if (select > p[j].rank_number) {
                int temp = select;
                p[i].rank_number = p[j].rank_number;
                p[j].rank_number = temp;
                
                int temp_2 = p[i].rank_index;
                p[i].rank_index = p[j].rank_index;
                p[j].rank_index = temp_2;
            }
        }
    }

    for (int i = 0; i < count - 1; ++i) {
        int min_index = i;

        for (int j = i + 1; j < count; ++j) {
            if (p[min_index].rank_number > p[j].rank_number) {
                min_index = j;
            }
        }

        // 최솟값의 위치를 찾은 후 교환
        if (min_index != i) {
            rank_info temp = p[i];
            p[i] = p[min_index];
            p[min_index] = temp;
        }
    }
