문자 지우기

문자열 my_string과 정수 배열 indices가 주어질 때,
my_string에서 indices의 원소에 해당하는 인덱스의 글자를 지우고 이어 붙인 문자열을 return 하는 solution 함수를 작성해 주세요.


1. 동적할당 할 문자열의 길이를 구합니다.


2. 이중 for문을 돕니다.
    => 외부 for은 문자열
    => 내부는 indices


3. 외부 for문에 bool is_removed = false;

4. 내부 for문에서 인덱스 i와 indices[j]를 비교해서 맞다면 is_removed를 true로 바꾸고 break;

5. 외부 for문 마지막에 if_removed가 false라면 추가합니다.
    => 이 때 동적할당한 index와 i는 일치하지 않기에 for 외부에 지역변수를 사용해서 값을 증가시킵니다.
