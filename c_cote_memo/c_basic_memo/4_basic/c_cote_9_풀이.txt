특별한 2차원 배열 2

n × n 크기의 이차원 배열 arr이 매개변수로 주어질 때, arr이 다음을 만족하면 1을 아니라면 0을 return 하는 solution 함수를 작성해 주세요.

0 ≤ i, j < n인 정수 i, j에 대하여 arr[i][j] = arr[j][i]


1. 매개변수 타입이 int ** 일 때
    => 2차원 배열은 줄 수 없습니다.
    => 이 떄는 2중 포인터 or 포인터의 배열만 줄 수 있습니다.


2. arr[i][j] == arr[j][i]를 검사하고 만약 다르다면 result = 0으로 만들고 return 하면 됩니다.
