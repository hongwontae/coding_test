부분 문자열 이어 붙여 문자열 만들기

길이가 같은 문자열 배열 my_strings와 이차원 정수 배열 parts가 매개변수로 주어집니다.
parts[i]는 [s, e] 형태로, my_string[i]의 인덱스 s부터 인덱스 e까지의 부분 문자열을 의미합니다.
각 my_strings의 원소의 parts에 해당하는 부분 문자열을 순서대로 이어 붙인 문자열을 return 하는 solution 함수를 작성해 주세요.


1. solution_1 풀이
    1-1. 이중 포인터를 생성합니다.
    1-2. 이중 포인터 내의 각각의 요소에게 my_string[i]에 해당하는 문자를 집어 넣습니다.
    1-3. 전체 문자열 길이를 토대로 동적 할당한 배열을 만듭니다.
    1-4. 길이를 알아내고 문자열에 집어넣습니다.


2. solution_2 풀이
    2-1. 전체 문자열 길이를 바로 계산합니다.
        => parts의 행의 개수는 랜덤이지만 col의 개수는 2개입니다.
        => 즉, [i] - [i-1] + 1 -> 부분 문자열 개수입니다.
        => 이걸 다 합산하면 return 할 문자열의 개수가 나옵니다.
    
    2-2. 문자열을 heap 동적 할당합니다.

    2-3. 문자열을 바로 복사합니다.
        => 전체 길이만큼 반복합니다.
        => s를 시작점, e를 마지막 지점으로 하고 part[i][0], parts[i][1]로 설정합니다.
        => 초기값은 j = s로 두고 조건문은 s<=e로 두고 j를 증가시킵니다.
        => answer[index] = my_strings[i][j]; index++;
