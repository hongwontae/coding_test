배열 만들기 1

정수 n과 k가 주어졌을 때,
1 이상 n이하의 정수 중에서 k의 배수를 오름차순으로 저장한 배열을 return 하는 solution 함수를 완성해 주세요.


1. 동적 할당할 길이를 알아야 합니다.
    => 1이상 n 이하의 범의 숫자에서 k의 배수를 길이를 알아야 합니다.
    => n/k -> 배수의 길이입니다.


2. for문으로 길이 만큼 돌립니다.
    => 지역 변수로 acc를 두고 초기값은 k로 둡니다.
    => for문이 돌아갈 떄 acc가 n을 넘으면 break;
    => 내부 로직은 p[i] = acc; acc+=k;
