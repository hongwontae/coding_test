문자열 묶기

문자열 배열 strArr이 주어집니다. 
strArr의 원소들을 길이가 같은 문자열들끼리 그룹으로 묶었을 때
가장 개수가 많은 그룹의 크기를 return 하는 solution 함수를 완성해 주세요.


1. 선택 정렬 알고리즘을 사용했습니다.

2. 문자열 배열의 각 요소의 길이를 구해서 int []에 담습니다.
    => 길이는 문자열 배열의 길이와 일치합니다.


3. 이중 for문을 사용해서 선택정렬을 시작합니다.
    => 이 떄 외부 for은 고정된 요소 / 내부 for은 옮길 요소
    => 그리고 값의 변경은 for의 세 번쨰 -> 이거 잠시 망상함
    => 내부 for문에서 비교문을 통해 숫자가 일치하면 for 외부문의 지역변수 ++
    => 그리고 바깥 result와 비교해서 temp가 더 높다면 대체
    => 모든 작업이 끝나면 return result

    4-1. str_arr의 원소의 길이는 30이하입니다. / int cnt [31] = {0}; 초기화 
    4-2. for문을 str_arr의 길이만큼 돌리고 각 문자의 길이를 strlen으로 구합니다.
    4-3. 그 len을 cnt[len]++을 통해 집어넣습니다. -> 1이 두개면 cnt[1]은 2개.. 3이 3개면 cnt[3]은 3개..
    4-4. for문을 30번 돌립니다. cnt[i]를 비교해서 제일 높은 값을 찾고 return 합니다.
