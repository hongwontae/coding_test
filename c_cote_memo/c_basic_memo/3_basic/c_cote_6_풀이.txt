배열의 길이에 따라 다른 연산하기

정수 배열 arr과 정수 n이 매개변수로 주어집니다.
arr의 길이가 홀수라면 arr의 모든 짝수 인덱스 위치에 n을 더한 배열을,
arr의 길이가 짝수라면 arr의 모든 홀수 인덱스 위치에 n을 더한 배열을 return 하는 solution 함수를 작성해 주세요.


1. 배열의 길이가 홀수인지 짝수인지에 따라서 분기를 냅니다.


2. 배열의 길이가 짝수라면 홀수 인덱스에 n를 더한 값을 만들어야 합니다.

3. 배열의 길이가 홀수라면 짝수 인덱스에 n를 더한 값을 만들어야 합니다.

4. for문을 사용해서 내부의 if문으로 짝수, 홀수를 구분해서 n를 더해서 동적할당한 곳에 넣으면 됩니다.
