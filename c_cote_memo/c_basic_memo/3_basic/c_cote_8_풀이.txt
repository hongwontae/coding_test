간단한 식 계산하기

문자열 binomial이 매개변수로 주어집니다. binomial은 "a op b" 형태의 이항식이고
a와 b는 음이 아닌 정수, op는 '+', '-', '*' 중 하나입니다. 주어진 식을 계산한 정수를 return 하는 solution 함수를 작성해 주세요.


1. solution_1 풀이
    1-1. 기존의 데이터에 변형이 들어갈 예정이고 매개변수가 const이기에 문자열을 복사합니다.
    1-2. 문자열을 잘라서 각각의 문자열로 만들 예정입니다. 그리고 len은 3개입니다. -> char * arr [3];
    1-3. strtok_r()를 통해서 공백을 기준으로 널을 추가하여 각각의 문자열을 만들 예정입니다.
    1-4. while에서 strlen, arr[i], 동적할당을 통해서 값을 넣습니다.
    1-5. 그리고 각 값을 atoi/ 인덱스 접근을 통해 얻고 계산하여 return 합니다.


2. solution_2 풀이
    2-1. char * arr [] -> 값에 char *가 존재하는 배열입니다.
        => 즉, 각 값은 주소를 갖고 있습니다.
    2-2. 이 값에 각각의 문자열의 첫 번쨰를 넣어주면 됩니다.
        => 대부분의 문자열 함수는 \0를 기준으로 기능합니다.
    2-3. strtok_r를 통해서 공백을 통해서 각 문자열의 첫 주소를 넣고 바로 전달합ㄴ다.
    2-4. 각 값을 atoi, 인덱스 접근을 통해 계산하고 return 합니다.
