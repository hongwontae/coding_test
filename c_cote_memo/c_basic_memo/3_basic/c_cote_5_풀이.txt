정수로 이루어진 문자열 n_str이 주어질 때,
n_str의 가장 왼쪽에 처음으로 등장하는 0들을 뗀 문자열을 return하도록 solution 함수를 완성해주세요.


1. 문자열 중 가장 왼쪽부터 검사를 시작합니다.
    => 이 떄 0이 나오면 제거를 하고 0이 아닌 문자가 나오면 정지합니다.
    => 그리고 그 나머지 문자열을 반환해야 합니다.


2. solution_1
    2-1. strlen(n_str)로 전체 길이를 알아내고 지역 변수에 대입합니다.
    2-2. for문을 사용해서 '0'이 나오면 --length하고 그렇지 않으면 break;합니다.
        => 첫 번쨰 문자부터 검사하기 떄문에 올바른 길이가 나옵니다.
    2-3. 동적할당을 하고 널 문자를 고려합니다.
    2-4. for문을 사용해서 0을 빼는 작업을 시작합니다.
        => n_str[i] == '0'이거나 current_time == 0이라면 continue 합니다.
        => current_time은 '0'을 만나지 않은 else에서 current_time을 1로 바꿔줍니다. -> 그러면 '0'이 중간에 있는 것을 거르지 않습니다.


3. solution_2
    3-1. 지역변수 index를 선언합니다.
    3-2. while (n_str[i] == '0')를 통해 index를 구합니다. -> '0'이 아닌 수가 나올 떄까지 '0'의 개수
    3-3. 그리고 동적할당을 시작하는데 포인터 연산은 자료형 크기만큼 이동하는 것을 이용합니다.
        => 즉, strlen(n_str + index) + 1 -> 0011 이면 1부터 바라봅니다. -> 최종 3개
    3-4. 그리고 strcpy(동적할당, n_str+index);로 처리합니다.
        => 그대로 값이 복사되고 널도 추가해줍니다.
