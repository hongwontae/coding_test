문자열 정수의 합

한 자리 정수로 이루어진 문자열 num_str이 주어질 때, 각 자리수의 합을 return하도록 solution 함수를 완성해주세요.


1. 문자는 내부적으로 숫자로 저장됩니다. 
    => char one_char = '3';
    => ASCII 기준으로 정수로 변환되고 이 값을 이진수로 저장합니다.
    => 문자 0, 1, 2, 3, 4.. 9는 서로 연속적인 숫자 코드를 가지고 있습니다.
    => '0' = 48 / '1' = 49 / '2' = 50 / '3' = 51 / '4' = 52
    => 그렇기에 char 3은 51 / 0은 48 -> 51 - 38 = 3; -> 이걸 int로 표현


2. 내부 흐름
    => char + char는 문자 코드 + 문자 코드로 계산이 이뤄지고 그 값을 이진수로 저장합니다.
    => 그리고 그걸 받을 자료형이 무엇인지, 그걸 받을 형식지정자 무엇인지에 따라 다르게 표현됩니다.
    => 코드에서는 acc가 int 자료형 -> acc+='1' - '0' -> 문자코드 정수값으로 차곡차곡 쌓입니다.
