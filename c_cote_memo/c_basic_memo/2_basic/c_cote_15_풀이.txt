이어 붙인 수

정수가 담긴 리스트 num_list가 주어집니다.
num_list의 홀수만 순서대로 이어 붙인 수와 짝수만 순서대로 이어 붙인 수의 합을 return하도록 solution 함수를 완성해주세요.


1. 리스트에서 요소의 값이 홀수인지, 짝수인지 판별해야 합니다.
    => 전체 for문 + if n%2을 사용해서 요소가 짝수인지 홀수인지 확인합니다.


2. 정수를 c로 바꿔서 문자열에 넣습니다.
    => 0 ~ 9의 정수를 문자로 바꾸는 방법은 '0' + n 입니다.
    => 모든 문자는 ASCII 코드 포인트로 변환될 수 있습니다. -> 연산시 이 코드 포인트로 계산합니다.
    => 0 ~ 9는 1씩 증가하는 코드 포인트로 마치 배열처럼 이어져 있습니다.
    => 그렇기에 '0' + n은 -> 코드 포인트 48 + 3 -> 51 -> 3;


3. 지역 변수는 4개 존재합니다.
    => 짝수를 담을 문자열 배열과 짝수의 인덱스
    => 홀수를 담을 문자열 배열과 홀수의 인덱스


4. 모든 처리를 하면 atoi를 사용해서 더해서 반환할 수 있습니다.
