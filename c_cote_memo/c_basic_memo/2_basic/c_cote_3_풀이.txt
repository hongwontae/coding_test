공백으로 구분하기 2
단어가 공백 한 개 이상으로 구분되어 있는 문자열 my_string이 매개변수로 주어질 때,
my_string에 나온 단어를 앞에서부터 순서대로 담은 문자열 배열을 return 하는 solution 함수를 작성해 주세요.


1. 개념 정리
    1-1. malloc의 반환값은 주소입니다. -> 그 메모리 주소에는 값이 존재합니다.
    1-2. malloc으로 받은 주소 값을 free(address)하면 그 주소-메모리 값은 반환됩니다.

    1-3. strtok_r()은 첫 번쨰 인자로 받은 문자열을 수정합니다.
    1-4. strtok_r()은 구분자를 찾으면 널 문자를 자동으로 추가합니다.


2. char ** pp = (char **) malloc (sizeof(char *) * 3);
    => pp[i] = (char) malloc (sizeof(char) * n);
    => 대전제 -> malloc은 공간을 확보하고 그 공간의 주소를 반환합니다.
    => 첫 번째 동적 할당은 공간에 char포인터가 존재하고 3개가 연달아 존재합니다.
    => 그리고 첫 번째 주소를 pp에 전달합니다. -> 그래서 이 구조가 이중 포인터입니다.
    => 그리고 두 번쨰 동적할당은 공간에 char n개가 연달아 존재하고 그 첫 번째 주소를 반환합니다.
    => 그래서 pp[n]은 첫 번쨰 char가 존재하는 주소를 가진 포인터입니다.
    => 이 떄 pp[n1][n2]는 char에 접근합니다. -> 이 떄 타입은 char입니다.


3. 흐름 정리
    3-1. strtok_r를 통해서 공백을 기준으로 문자열을 가져올 것입니다.
        => 이 떄 기존 문자열을 수정하기에 복사합니다.
    
    3-2. C 언어에서 배열의 길이는 정적입니다. -> 바꿀 수 없습니다.
        => 전체적인 길이를 알 수 있는 로직을 strtok_r를 통해서 얻습니다.
    
    3-3. 두 번쨰 strtok_r를 통해서 잘라낸 문자열의 길이, 문자열 자체를 복사해서 동적할당합니다.
