문자열 여러 번 뒤집기

문자열 my_string과 이차원 정수 배열 queries가 매개변수로 주어집니다.
queries의 원소는 [s, e] 형태로, my_string의 인덱스 s부터 인덱스 e까지를 뒤집으라는 의미입니다.
my_string에 queries의 명령을 순서대로 처리한 후의 문자열을 return 하는 solution 함수를 작성해 주세요.


1. copy_data를 먼저 구성합니다.


2. for문을 두 번 사용합니다.
    => 외부 for문은 queries_row
    => 내부 for문은 loop_total -> int loop_total = (qu_2-qu_1+1)/2;


3. 내부 for문의 총 루프 횟수을 알게되었으니 index만 조정해주면 됩니다.
    => 마지막과 처음을 바꾸고 마지막 -1 / 처음은 +1로 총 루프 횟수만큼 돌리면 됩니다.
