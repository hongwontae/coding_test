2의 영역

정수 배열 arr가 주어집니다. 배열 안의 2가 모두 포함된 가장 작은 연속된 부분 배열을 return 하는 solution 함수를 완성해 주세요.

단, arr에 2가 없는 경우 [-1]을 return 합니다.


1. 배열에서 2가 얼마나 나오는지 for문으로 세고 count가 0이나 1이면 그에 따른 처리를 합니다.


2. 배열을 생성해서 주어진 배열 2와 일치하면 그에 따른 인덱스를 넣습니다.
    => 이렇게 하면 첫 번째 요소는 2가 나오는 처음, 마지막 요소는 2가 나오는 마지막입니다.


3. 동적할당을 합니다. -> 이 떄 last_index - first_index + 1를 해서 영역 계산을 합니다.


4. for 문을 사용해서 채워넣고 return 합니다.
    => i는 first_index로 조건은 i가 1증가할 떄 i<=last_index
