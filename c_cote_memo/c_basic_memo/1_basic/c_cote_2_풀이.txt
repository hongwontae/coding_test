1. char *arr [] = {"Hong", "KKKK", "koALA3121"};
    => *보다 [] 연산 순위 높음
    => arr은 n개 짜리 배열이다 + 그 n개 짜리 배열 하나 하나 요소는 char 포인터이다. -> 이렇게 해석해야 합니다.


2. 위처럼 배열이 존재할 때 하나의 char 배열로 만들어서 %s를 통해 한 번에 표현해야 합니다.


3. C는 배열의 크기를 미리 알아야 합니다. -> total_length 필요
    => for문을 포인터 배열의 크기만큼 돌립니다.
    => 그리고 내부에서 strlen을 통해서 각 포인터 배열 요소를 대문자로 접근 + strlen을 사용해서 각 길이를 알아냅니다.
    => 그리고 for 외부 변수에 total_length로 더합니다.


4. malloc + total_length+1를 통해 힙 영역을 가져옵니다.
    => +1은 널문자 판단


5. 그리고 malloc char 포인터 변수에 차곡차곡 쌓기 위해서 이중 for문을 사용합니다.
    => 외부 for i는 포인터 배열의 각 요소
    => 내부 for j는 포인터 배열의 문자열의 각 요소
    => 그리고 for 외부에 지역변수 index를 두어서 -> 내부 for문이 돌 떄마다 +1를 해야 순서대로 쌓입니다.


6. 그리고 마지막 널 문자를 추가하고 printf()로 확인하고 return 0로 종료합니다.
