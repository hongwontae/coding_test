문자열 my_string과 정수 k가 주어질 떄, my_string을 k번 반복한 문자열을 return하는 main 함수를 작성해 주세요
"string" | 3 -> "stringstringstring"


1. C 언어에서는 배열의 크기를 동적으로 선언할 수 없습니다.
    => 인자로 받은 문자열의 크기와 k번을 곱한 문자열의 크기를 구해야합니다.
    => strlen()를 통해서 구합니다. 이 떄 널문자 전까지 읽기 떄문에 +1과 \0을 추가하는 판단을 해야합니다.


2. 최종 문자열의 크기는 순서대로 넣어야 합니다. -> for 외부에 지역변수 int index = 0; -> for 내부에서 로직 실행 후 증가시켜야 합니다.

3. for문을 두 번 사용해야 합니다.
    => 외부 for문은 k번 반복
    => 내부 for문은 문자열 길이 만큼 돌려야합니다.
    => 이 떄 내부 for문 로직으로 최종 문자열에 매개변수 문자열을 순차대로 넣고 index+=1; 작업을 합니다.
