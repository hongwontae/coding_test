문자열로 변환

정수 n이 주어질 때, n을 문자열로 변환하여 return하도록 solution 함수를 완성해주세요.


1. 정수 n이 어떤 절차를 거쳐서 문자 or 문자열이 됩니다.
    => 0 ~ 9는 char
    => 10 ~ n은 char []
    => 이 떄 조건이 10000이하 -> char [5]


2. 정수 2 -> 문자 '2'로 바꾸는 방법
    => 정수 + '0'을 하면 문자열 정수 그대로 나옵니다.
    => int + char 계산은 더 큰 byte를 기준으로 계산이됩니다.
    => 그리고 '0', '1'은 문자코드 상에서 48, 49 처럼 1씩 증가합니다.
    => int 2 + 문자코드상 0 48 -> 50 -> 이걸 다시 char -> 2 -> '2'가 됩니다.


3. 정수 10 -> 문자 '10'으로 바꾸는 방법
    => sprintf(문자열_첫_주소, "형식지정자", 형식지정자에_맞는_변수);
    => snprintf(문자열_첫_주소, 사이즈, "형식지정자", 형식지정자에_맞는_변수);
