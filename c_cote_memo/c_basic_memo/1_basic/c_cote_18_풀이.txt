두 수의 연산값 비교하기

연산 ⊕는 두 정수에 대한 연산으로 두 정수를 붙여서 쓴 값을 반환합니다. 예를 들면 다음과 같습니다.
12 ⊕ 3 = 123
3 ⊕ 12 = 312
양의 정수 a와 b가 주어졌을 때, a ⊕ b와 2 * a * b 중 더 큰 값을 return하는 solution 함수를 완성해 주세요.

단, a ⊕ b와 2 * a * b가 같으면 a ⊕ b를 return 합니다.


1. 정수형 a + b를 마치 문자열 붙이듯이 붙이고 int로 나타내라
    => 10 + 20 -> 1020 -> int


2. 이 떄 문제 접근을 두 가지로 볼 수 있습니다.
    2-1. 10과 20을 하나의 문자열로 붙이고 그 문자열을 숫자로 바꾸기
    2-2. 수학적 논리를 통해 if 문 분기 후 처리하기


3. case_2인 2 * a * b를 먼저 처리합니다. -> 그냥 표현식만 사용하면 됨


4. 2-1 접근법일 경우 char str [n];을 정의하고 sprintf();를 통해 하나의 문자열로 합칩니다.
5. 그리고 str을 atoi에 넣어서 정수로 변환한 값을 case_1에 대입합니다.
6. 삼항 연산자를 통해 조건에 맞게 return 합니다.


7. 2-2. 접근법의 경우 10 + 20 -> 1020입니다. 이 떄 총 2자리 수는 4자리입니다. / 25 + 9 -> 259 -> 총 자리 수는 3자리 입니다.
8. 이 떄 공식은 b의 자리수만큼 a가 확장되고 b를 더하면 됩니다. 10 + 20 -> 1000 + 20 -> 1020 / 25 + 9 -> 250 + 9 = 259
9. 즉, b가 10보다 작으면 a * 10 / 100보다 작으면 a * 100... 후 계산하면 됩니다.
