1. strlen()은 문자 배열 or 포인터에서 널 문자를 식별하고 count 하는 함수입니다.
    => 즉, 배열의 길이를 식별하는게 아닙니다.
    => 내부적으로 for문을 통해 널 문자를 식별하면 멈추고 count를 반환합니다.
    => 그렇기에 제대로 된 문자열의 길이는 strlen() + 1 입니다.
