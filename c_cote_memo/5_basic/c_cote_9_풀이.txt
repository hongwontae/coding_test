1. solution_1 풀이
    1-1. 구조체를 선언합니다. number와 rank를 담는 구조체
    1-2. for문으로 구조체를 담습니다.
    1-3. 선택정렬로 구조체 배열을 정렬합니다.
    1-4. 그리고 0, 1, 2에 접근해서 계산합니다.


2. solution_2 풀이
    2-1. select 배열과 int count를 선언합니다.
    2-2. 이중 for문을 돌리는데 rank 배열에는 겹치는 수가 없고 숫자가 낮을수록 등수가 높습니다.
        => 이 정보를 바탕으로 for외부에 r=1 / for 내부에 i =0 
        => 내부에 rank[i] == r 이고 attendance가 true라면 -> 그렇지 않은경우 1,2,3.. 이렇게 넘어갑니다.
        => 등수를 제대로 뽑을 수 있고 출석도 제대로 뽑을 수 있습니다.
        => 만약 해당된다면 count++;
    2-3. count == 3이라면 0, 1, 2 요소를 가지고 계산하여 return 합니다.
